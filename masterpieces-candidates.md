# MUSE — Nouvelles candidates

64 objets exacts vérifiés, 25 recommandations publiables, 22 cas bloqués pour les images. Les autres pistes restent explicitement non vérifiées. Aucun ajout au jeu.

## Méthode et limites

V2 2.0.0, P/A/H/M/C = 25/20/25/20/10, seuils 40/60/75/90. Aucun bonus nominal, aucun score ajusté pour atteindre 90. Scores et intervalles détaillés, données d’entrée et empreintes des preuves dans le JSON. Les pairs sont les 100 historiques non imputés ; les nouvelles cibles ne se normalisent pas entre elles. Audiences anglaises sur 12 mois complets (octobre 2025–septembre 2026) uniquement pour les identités exactes concordantes, jamais une série ni une civilisation. Les erreurs de collecte ne valent pas zéro. Les champs absents sont estimés via V2. Les références bibliographiques et expositions institutionnelles sont découpées par paragraphes et dédupliquées ; ce sont des proxies, pas une validation indépendante de chaque publication.

Les scores parfois bas des icônes reflètent les manques de collecte (notamment audiences exactes, références structurées, contexte d’auteur) et les priors prudents, pas un jugement concluant d’insignifiance. M mesure les signaux documentés, pas le prestige du nom du musée. Amélioration future : collecter les pages exactes multilingues et les bibliographies manquantes, puis recalculer en simulation ; ne pas modifier les seuils pour cette liste. Tous les résultats restent soumis à validation et le statut de chaque proposition est explicite.

## Sélection et diversité

{"Europe":12,"Amériques":4,"Asie":4,"Afrique":4,"Océanie":1}. La sélection mêle icônes reconnues et objets de référence pour élargir les traditions représentées ; ne pas présenter tous ces objets comme également célèbres. Les identifiants muséaux sont la référence ; Wikidata absent est conservé null. Les œuvres anonymes n’héritent pas de l’audience entière de leur culture.

## Reproduction et futur import

Depuis la racine :

    npx tsx scripts/masterpieces/audit.ts
    npx tsx scripts/masterpieces/build.ts
    npx tsx scripts/masterpieces/images.ts
    npm test
    npm run build:atelier
    npm run deploy:atelier

Le build des rapports est hors réseau ; images.ts refuse tout objet non recommandé ou sans droits établis. Le déploiement ne vise que l’atelier. Pour une revue locale : ouvrir /masterpieces.html. Exporter les choix avec le format muse-masterpieces-review, séparé des décisions du millier. **Aucune commande d’import dans le jeu n’est fournie** : sa migration requiert une validation et un mapping vers CatalogDataset, pas une copie du preview. Le preview réutilise ReviewArtwork mais n’est volontairement pas accepté par parseReviewCatalog (contrat figé de 1000).
