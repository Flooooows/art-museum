# Historique — ne décrit pas l'état actuel

Ces documents décrivent les livraisons successives des 29–30 octobre 2026. Leurs anciens nombres de cartes, d'œuvres, leurs chemins et résultats de tests sont conservés comme traces datées, **pas comme instructions actuelles**.

- `plans/` : les douze plans terminés, auparavant dans `execplan/`.
- `reviews/` : les comptes rendus historiques de vérification visuelle, auparavant dans `.impeccable/review/`. Leurs captures temporaires ne sont pas versionnées.
- `bootstrap/` : texte des deux anciens scripts de téléchargement et de recadrage, désormais archivés avec le suffixe `.txt`. Ils ne font plus partie de l'outillage actif et ne doivent pas servir à mettre à jour les 100 œuvres.

Pour travailler sur le projet : [index documentaire](../README.md), [état actuel](../ETAT_ACTUEL.md), [architecture](../ARCHITECTURE.md).

Les anciens rapports de recherche et preuves restent dans les dossiers `catalog/` correspondants ; les sources retirées encore nécessaires aux empreintes sont dans `catalog/history/`.
