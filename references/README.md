# Références visuelles conservées

- `mockups/` : les quatre maquettes HTML/PNG et leur direction artistique d'origine, fournies pour créer MUSE. Ce ne sont pas des pages de l'application courante.
- `cards/` : `exemplecarte1.png` et `exemplecarte2.png`, références utilisateur conservées intactes.
- `illustrations/` : quatre anciens visuels de maquettes retirés de `public/assets/`, sans usage dans l'interface actuelle. Leurs anciens noms et sources restent documentés dans `public/assets/provenance.json` comme historique ; ils ne sont plus déployés.

Les originaux des cadres restent dans `public/assets/collections/` pour ne pas casser la préparation ni leurs preuves. Seuls les dérivés de `collections/display/` sont nécessaires au rendu ; la configuration Firebase du jeu exclut les originaux du déploiement.

Les cinq sources de génération des cadres Arts décoratifs restent dans `output/imagegen/`, à leurs chemins de provenance historiques. Rien dans ce dossier de références ne doit être pris pour une nouvelle autorisation de droits commerciaux.
