## Revue locale et reproduction

Les nouvelles cartes utilisent ReviewArtwork et l’interface existante, dans **/review-351.html**, avec une sauvegarde indépendante **muse:enrichment-351-review:v1**. Choix de rareté et Retenir/Écarter/Reporter/Réexaminer restent séparés et historisés. Le jeu et les deux anciennes clés ne sont jamais écrits par ce lot. Les exports d’une autre version sont refusés sans écrasement. Le JSON d’import est une prévisualisation de revue, pas CatalogDataset actif.

Depuis la racine :

    npx tsx scripts/enrichment-351/audit.ts
    npx tsx scripts/enrichment-351/prepare.ts
    npx tsx scripts/enrichment-351/images.ts
    npx tsx scripts/enrichment-351/build.ts
    npm test
    npx tsc -b
    npm run dev -- --host 0.0.0.0

Ouvrir ensuite /review-351.html. prepare et build sont hors réseau ; images ne récupère que les approbations documentées et réutilise les fichiers dont les empreintes correspondent. Pour actualiser les observations, les collecteurs séparés acceptent --live et conservent les réponses réussies. **Ne pas lancer Firebase pour ce lot.** Les configurations de publication excluent ces données locales, aucune commande d’activation de jeu n’existe.

Fichiers de livraison : enrichment-351-results.json (351 résultats, données de score, droits, sources et empreintes), enrichment-351-review.json (prévisualisation), catalog/enrichment-351/image-manifest.json (licences/crédits/qualité des rasters), et ce rapport.
